CUDA is now detected automatically. The default `--backend auto` uses an available
NVIDIA GPU and CUDA runtime, otherwise selects CPU and reports why. Runtime discovery
includes standard toolkit locations, CUDA environment variables and application-local
libraries. `--backend cuda` remains available to require GPU execution.

The Windows executable now uses the Ed25519 lookup table generated automatically
by the Rust build. The generator verifies every build against the original table's
SHA-256, and the generated data is embedded in the executable. The table binary is
no longer tracked in the source tree. Wallet derivation and recovery are unchanged.

Download the standalone `.exe` or the ZIP containing the executable, documentation,
and licenses. `SHA256SUMS` covers both downloads.

CPU mode runs without CUDA. GPU mode requires an NVIDIA driver and CUDA 13 NVRTC
with its matching builtins library; see the README for `--cuda-path` configuration.
